# Experimental hand-fitted art mod

This is an unofficial, for-fun visual experiment layered over the faithful remake.
It uses the player's unchanged `PEST.ADM` for the game and replaces only assets that
have been individually corrected. The default Smooth HD and Classic modes remain
untouched.

Current coverage: the room's idle `MEGA.FLC` megaphone. `megaphone.svg` is the
hand-fitted source; `megaphone.png` is its transparent 4× render embedded into the
single executable as a Windows resource. The pressed/animated megaphone and all
other sprites still use Smooth HD. Do not present the mod as a complete remaster.

New corrections should be fitted by hand against the owner's original data,
reviewed in-game at normal size, and added one asset/state at a time. Keep raw
original files, extracted frames, and full sprite dumps in ignored `original/` or
`work/`, not here. The mod artwork is a derivative fan interpretation, not a
replacement for the original game data.
